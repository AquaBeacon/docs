# 出典と提出要項の対応

## 公式要項

2026年11月6日に、第15回の[公式募集要項PDF](https://www.wxbunka.com/cms/wp-content/uploads/2022/11/contest_15th_0129.pdf)2ページの「報告書」欄と[公式コンテスト案内](https://www.wxbunka.com/contest/)を確認した。URLの保存先に2022年とあるが、PDF本文は2026年第15回の要項である。

| 要件 | 報告書への反映 |
| --- | --- |
| A4、タイトルを含め5ページ以内 | 5つのページに分け、WordによるPDF変換で実ページ数を確認 |
| フォント10ポイント以上 | 本文・表・写真キャプション・参考資料・ページ番号を10ポイント以上に設定 |
| 参加メンバーの氏名 | 1ページに氏名を記載。既存発表原稿を根拠とし、一次登録の全名簿との照合は提出者が行う |
| 目的、実証実験、結果、考察 | 1・3・4・5節で明示 |
| 継続作品は従来と今回を区別 | 2ページの「従来の取り組みと今回の内容」で区別。過去の受賞やチームの成果を今回の実証値として流用しない |
| 大量のデータ・写真は別付録 | 本体は写真2点と要点に限定。元の研究レポート・生データを本体へ連結しない |

二次審査の報告期限は2026年11月10日。ポスターや必要に応じたプレゼン動画は二次審査通過後の段階である。個別に届いた案内の書式・送付方法・ファイル名などは、この作業では確認できていない。WordとPDFは編集用・提出用として作成したものであり、PDF形式を公式の必須指定と解釈したものではない。

選考のポイントは、独創性、完成度、実用性、発展性、試行錯誤、観測・考察などの参考視点として構成に反映した。配点が決まった採点表や、全項目が必須のチェックリストとしては扱っていない。

## 水温の照合

[同期済み子機ログ](../../../aquabeacon-analysis/data/processed/20261101_nanyo_003/synchronized/child/C_MAIN_HEALTH_RANGE_68440.health.csv)の `sync_utc_s` が、2026年11月1日10時15分00秒以上・10時16分00秒未満（JST）の行を選択し、`temp_c` を確認した。

- 有限な温度記録：46件。実際の最初の記録は窓開始から約14.254秒後であり、窓全体を連続・一様に観測したとは扱わない。
- 記録値の範囲：24.3910217285～24.3995056152 °C。
- 算術平均：24.3934193487 °C。報告本文では「約24.4 °C」と表記した。
- センサーの独立校正は未実施。表示桁数を測定精度として主張しない。

この照合は既存ログの指定窓を読んだものであり、位置推定・マッピングの再解析や元データの変更は行っていない。温度統計と入力ハッシュはmanifest.jsonに記録する。生ログは本体・付録に複製していない。
