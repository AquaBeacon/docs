学校・学年・参加メンバー名は、現行の発表原稿の「兵庫県立長田高校2年・神山瑠星」を採用した。提出前に、一次応募時の作品名・学校名表記・参加メンバー全員の氏名、および個別に届いた提出案内との一致を確認する。報告書の送信・提出は行っていない。
