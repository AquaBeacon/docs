## 企画の中心

「光と音で、水中の位置を知る。藻場の地図づくりへ。」

水上の装置から音を送り、距離を測る。水中のライトを水上のカメラで捉え、方向を測る。その位置情報と子機の撮影データを結びつけ、藻場のマッピングを目指す開発として紹介する。

音響距離測定のプール実験は資料で確認できる。統合した位置推定・マッピングの性能は開発目標として扱い、実証済みとは表現しない。

一般向けには、**01の断面模型をベースに、03の図解と09の実験写真を加える組合せ**を推奨する。全体の位置関係をつかみやすく、仕組みと開発の現在地を同じ1分で伝えられる。

選ぶ際は「01をベース、03の文字、09の実験写真」のように、ベース1案と補助0〜2案を指定できる。制作ツールは**Blender**。横16:9・日本語ナレーション付きは仮設定で、選択時に変更できる。
